# Tic-Tac-Toe

Tic-tac-toe on squared paper, in one HTML file with no build step.

**Play it:** https://konart309.github.io/tic-tac-toe/

- **vs Computer**: Easy, or Unbeatable (perfect minimax play)
- **2 Players**: take turns on the same screen
- Running score, alternating first move, light and dark themes, keyboard play (Tab + Enter)

To run locally, open `index.html` in a browser.
